2. Ściągawka — co wpływa na co
Warunki (conditions) — wszystkie opcjonalne. Event pokaże się tylko, jeśli WSZYSTKIE są spełnione.

Pole	Znaczenie
yearMin / yearMax	Zakres lat
phase	["chaos"], ["duopol"], ["invasion"]
party	["PZPR"], ["independent"], ["none"], ["opposition"]
currentPartyId	["sld"], ["pis"], ["po"], ["psl"]...
rulingParty	Partie w koalicji rządzącej
mafiaMember	true / false
minStateKonta / maxStateKonta	Próg stanu konta
minReputation / maxReputation	Progi reputacji (dowolna sub-statystyka)
legalForm	["cywilna"], ["zoo"], ["sa"], ["holding"]
activities	["handel"], ["it"], ["produkcja"]...
flags	Wymagane flagi
notFlags	Wykluczone flagi
Efekty (effects i gamble.onWin/onLose)

Pole	Efekt
stateKonta	Zmiana stanu konta (+/−)
reputation	{ "opiniaPubliczna": +5, "opiniaMafia": -10 } — dowolna sub-statystyka
pasywa	{ "pracownicy": +5000 } — zwiększa koszty
aktywa	{ "przychodyZDzialalnosci": +10000 }
flagsAdd / flagsRemove	Dodaje/usuwa flagi
joinMafia / leaveMafia	true / false
setParty	"PZPR" / "independent" / "none" / "opposition"
setCurrentPartyId	ID partii z parties.json
Sub-statystyki reputacji (nazwy do reputation)

branza, opiniaPubliczna, opiniaPracownicy, opiniaBranza, opiniaMafia, opiniaMedia, opiniaPolitycy

Uwaga o weight — im wyższa liczba, tym częściej event się pojawia. Zasady:

Historyczne, mocne: weight: 100 (i once: true)

Średnie, klimatyczne: weight: 10–20

Rzadkie, mocne efekty: weight: 5–8
